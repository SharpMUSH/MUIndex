# MUIndex Read API, Plain Surface and Feeds — Implementation Plan (Plan 05)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `src/MUI.Web` from a placeholder into the read surface the spec describes — a read-only JSON API, a `?plain=1` text surface rendered from the *same* view models, ETagged and conditionally-cacheable, with presence and availability time series, bulk dumps, ecosystem shares, rankings and the three RSS liveness feeds — hosting Plan 03's `CrawlerService` in the same deployable.

**Architecture:** The `?plain=1` view-model seam is the spine, not a feature at the end. `MUI.Web.ViewModels` is built **first**; every surface (JSON, plain text, and the HTML page a later plan adds) renders from `IViewModelBuilder`'s output and nothing else. `PlainRenderer` walks those view models reflectively and formats leaves through the *same* `JsonSerializerOptions` the JSON surface uses, so the two surfaces cannot drift: there is no second document to drift into. A structural parity test compares the leaf paths and values of the JSON response with those of the `?plain=1` response for the same URL and fails on any difference. Provenance and staleness ride on every displayed fact, and staleness is `MUI.Catalog.FieldRegistry`'s answer — nothing downstream re-derives it (spec §5.6).

**Tech Stack:** .NET 10, ASP.NET Core minimal APIs, `System.Text.Json` (canonical serialisation for both surfaces and for ETag hashing), `System.Xml.Linq` for RSS 2.0, Npgsql + Dapper via Plan 02's `MUI.Storage` repositories, TUnit on Microsoft.Testing.Platform, `Microsoft.AspNetCore.Mvc.Testing`'s `WebApplicationFactory<Program>` and `Testcontainers.PostgreSql` for integration tests.

**Depends on: Plan 02 for `MUI.Storage`, the repositories, `FieldRegistry` and the migration runner; Plan 03 for the referral graph and `CrawlerService`, which this deployable hosts. Read-only: no endpoint in this plan writes anything.**

## Global Constraints

These apply to every task in this plan without being repeated.

- **Target framework `net10.0`**, and `TreatWarningsAsErrors` is `true` solution-wide
  (`Directory.Build.props`). A build with a warning is a failed build.
- **Tests are TUnit on Microsoft.Testing.Platform** (`Exe` projects). **`dotnet test` does not
  work** — .NET 10 dropped VSTest. Run each suite directly and keep the `</dev/null`, which
  detaches stdin so the test host does not hang waiting on it:
  ```bash
  dotnet build MUIndex.slnx -c Release
  dotnet run -c Release --no-build --project tests/MUI.Crawl.Tests </dev/null
  ```
- **Assertion idiom:** `await Assert.That(actual).IsEqualTo(expected);` — tests are
  `[Test] public async Task Name()` on a plain `public class`, no attributes on the class.
- **`.editorconfig`:** file-scoped namespaces, 4-space C# indentation, LF line endings, 2-space
  indentation for `csproj`/`props`/`json`/`yml`/`slnx`.
- **`MUI.Catalog` must NEVER reference `MUI.Crawl`.** The writers that consume a probe result must
  not know a socket exists; that one-way arrow is what keeps every downstream behaviour testable
  against a captured `ProbeResult` fixture with no network involved.
- **Never persist player names.** `WHO` is parsed in memory; aggregates use salted hashes with a
  rotating salt, so a unique-player estimate is possible while re-identification across salt epochs
  is not.
- **Parsers never fabricate.** An unreadable `WHO` yields `WhoConfidence.Unknown`, never zero — and a
  `WHO` that was never sent yields `WhoConfidence.NotAttempted`, which is a different state.
- **Vocabulary is "reachable", never "uptime"** — schema, API, code and copy alike (spec §5.7).
- **Branch from `main`, open a PR, never commit directly to `main`.**
- **Any new test project goes into `MUIndex.slnx` AND `.github/workflows/ci.yml`**, which runs each
  suite as its own explicit step.
- **MUIndex owns the MSSP domain** — namespace `MUI.Crawl.Mssp`, in `src/MUI.Crawl`, Plan 01's code
  written against Plan 01's own tests. There is **no shared package**: nothing named `SharpMU.Mssp`
  was ever published and the repository that would have produced it is archived, so MUIndex
  implements its crawler end to end and shares no code with SharpMUTerm. `MsspData`, `MsspHost`,
  `MsspHostScope` and `MsspVariables` live there; telnet option 70 is parsed by
  `TelnetNegotiationCore` 2.7.0 itself, and `MUI.Crawl.Mssp.MsspPlaintextReply` handles only the
  out-of-band `MSSP-REQUEST` text reply. Never re-declare those types locally.
- **Persistence is PostgreSQL 17 with Npgsql + Dapper and plain numbered `.sql` migration files
  applied by a small idempotent runner. No EF Core**, ever. Integration tests use
  `Testcontainers.PostgreSql`.

## Contract deviations and assumptions

`CONTRACT.md` is authoritative and its default is "copy verbatim". Six places need more than it
gives, and the contract itself says a plan that needs a change must say so. These are all of them.

**One contract change is not a deviation but a supersession.** The contract addendum (§1, §2) retires
the `SharpMU.Mssp` package — it was never published and the repository that would have produced it is
archived — and moves the MSSP domain into `MUI.Crawl.Mssp` as Plan 01's own code. For this plan that
is a namespace and a deleted `PackageVersion` and nothing else: the only MSSP type `MUI.Web` touches
is `MsspVariables`, reached through the `MUI.Discovery` → `MUI.Crawl` reference this deployable
already has for `ProbeSession`.

1. **`IGameRepository.CountAsync(GameQuery, CancellationToken)` is added** (Task 6). `CollectionView<T>`
   carries a `Total` and no contract method produces one. Task 6 pins it with a test that
   `CountAsync` and an unpaged `ListAsync` agree, so a divergent predicate is a red test rather than
   a wrong number.
2. **Three batched reads are added** (Task 6): `IGameFieldRepository.ForGamesAsync`,
   `IAvailabilityRepository.RangeForGamesAsync`, `IPresenceRepository.LatestForGamesAsync`. A
   50-row collection page needs codebase, presence and 90-day availability per row; without batching
   that is 150 round trips per request. The reachability arithmetic still lives in exactly one place
   (`ReachabilityCalculator`) — these methods fetch rows, they do not compute.
3. **Two read-only readers are added to `MUI.Storage`** (Tasks 14, 15): `IFeedReader` (the three
   liveness feeds) and `IEcosystemReader` (codebase/protocol shares plus a dataset version stamp).
   Plan 02 has no feed or aggregate concept; these are new types, not changes to contract types.
4. **Two routes are added beyond the contract's table**: `GET /api/v1/ecosystem/shares` and
   `GET /api/v1/rankings` (spec §9 requires both; no other plan consumes them).
5. **The bulk dump's ETag is over a dataset version stamp, not over the body.** A strong ETag is a
   hash of the body and the body is streamed precisely so it never exists in memory. The stamp is
   `(total games, max(field_change.at), licence string)`, which is stable with no intervening write
   and changes when the data changes — the two properties the contract asks the ETag to have.
6. **`MUI.Web` does not reference `MUI.Backfill`.** Nothing in a read endpoint needs an importer.
   §7.6's attribution list reaches the dump through `IAttributionSource`, whose default
   implementation reads configuration; Plan 04 may register an importer-backed one later.

**Reading Plan 02's and Plan 03's storage.** This plan is written before those exist. Three details
they own are not pinned by the contract, and every place this plan guesses one, a test catches the
guess being wrong rather than a wrong answer reaching a caller:

- **Concrete repository class names.** DI in Task 1 registers `NpgsqlGameRepository`,
  `NpgsqlGameFieldRepository`, `NpgsqlPresenceRepository`, `NpgsqlAvailabilityRepository`, `NpgsqlEndpointRepository`,
  `NpgsqlCrawlTargetRepository`, `NpgsqlReferralRepository`, `NpgsqlMergeLog`. If Plan 02 or Plan 03 shipped a
  `services.AddMuiStorage(...)` / `services.AddMuiDiscovery(...)` extension, call that instead and
  delete the corresponding lines. A wrong name is a compile error, which is the good failure.
- **Column names and enum storage.** New SQL in Tasks 6, 14 and 15 uses the column names spec §5.1,
  §5.2, §5.3 write down verbatim and assumes enums are stored as lower-case text
  (`'archived'`, `'handshake'`, `'reachable'`). **Open the neighbouring repository in the same file
  and copy its `SELECT` list, its parameter binding and its enum conversion exactly**; change only
  the `WHERE`. The agreement test in Task 6 and the integration tests in 14 and 15 fail loudly if
  the guess is wrong.
- **`ReferralEdge`'s shape.** The contract references it in `IReferralRepository` without defining
  it. This plan reads `FromGameId`, `ToHost`, `ToPort`, `FirstSeenAt`, `LastSeenAt`, `Present` —
  the tuple spec §7.1 writes down. If Plan 03 named them differently, only
  `ViewModelBuilder.ReferralNeighbours` changes.

**Field-name literals are forbidden in this plan's code.** Every field name comes from
`MUI.Catalog.FieldRegistry`, from `MUI.Crawl.Mssp.MsspVariables`, or from `MUI.Web.WellKnownFields` —
and `WellKnownFields` is pinned by a test asserting the registry declares every name in it (Task 5),
so a spelling mismatch with Plan 02 is a red test rather than a silently null tagline.

```csharp
using Microsoft.AspNetCore.Hosting;
using Microsoft.AspNetCore.Mvc.Testing;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using MUI.Storage;
using Npgsql;
using Testcontainers.PostgreSql;

namespace MUI.Web.Tests.Support;

/// <summary>
/// The app, hosted in-process against its own freshly migrated database on a container shared by the
/// whole test session. Each factory gets its own database so a collection test can count rows without
/// another test class's fixtures in the way.
/// </summary>
public sealed class MuiWebFactory : WebApplicationFactory<Program>, IAsyncInitializer
{
    private static readonly SemaphoreSlim ContainerGate = new(1, 1);
    private static PostgreSqlContainer? _container;

    /// <summary>Descriptor types registered as hosted services, captured before the host starts.</summary>
    public static IReadOnlyList<Type> HostedServiceTypes { get; private set; } = [];

    public string ConnectionString { get; private set; } = string.Empty;

    public FixedTimeProvider Clock { get; } = new(Seed.Now);

    public async Task InitializeAsync()
    {
        var container = await ContainerAsync();
        var database = $"mui_{Guid.NewGuid():N}";

        await using (var admin = NpgsqlDataSource.Create(container.GetConnectionString()))
        await using (var command = admin.CreateCommand($"CREATE DATABASE \"{database}\""))
        {
            await command.ExecuteNonQueryAsync();
        }

        ConnectionString = new NpgsqlConnectionStringBuilder(container.GetConnectionString())
        {
            Database = database,
        }.ConnectionString;

        await using var source = NpgsqlDataSource.Create(ConnectionString);
        await new MigrationRunner(source).ApplyAsync(CancellationToken.None);
    }

    protected override void ConfigureWebHost(IWebHostBuilder builder)
    {
        builder.UseSetting("ConnectionStrings:mui", ConnectionString);

        // Nothing in this suite may dial a stranger's telnet port.
        builder.UseSetting("Crawler:Enabled", "true");

        builder.ConfigureServices(services =>
        {
            HostedServiceTypes = services
                .Where(d => d.ServiceType == typeof(IHostedService) && d.ImplementationType is not null)
                .Select(d => d.ImplementationType!)
                .ToList();

            // Registration is the property under test; running the loop is Plan 03's business and
            // would put a real socket in a unit test's way.
            foreach (var hosted in services.Where(d => d.ServiceType == typeof(IHostedService)).ToList())
            {
                services.Remove(hosted);
            }

            services.AddSingleton<TimeProvider>(Clock);
        });
    }

    private static async Task<PostgreSqlContainer> ContainerAsync()
    {
        await ContainerGate.WaitAsync();
        try
        {
            if (_container is null)
            {
                _container = new PostgreSqlBuilder().WithImage("postgres:17-alpine").Build();
                await _container.StartAsync();
            }

            return _container;
        }
        finally
        {
            ContainerGate.Release();
        }
    }
}
```

```csharp
using Microsoft.Extensions.DependencyInjection;
using MUI.Catalog;
using MUI.Storage;

namespace MUI.Web.Tests.Support;

/// <summary>Every shape of row the read surfaces have to render, written through Plan 02's repositories.</summary>
public static class Seed
{
    public static readonly DateTimeOffset Now = new(2026, 7, 30, 12, 0, 0, TimeSpan.Zero);

    public static async Task<Game> GameAsync(
        IServiceProvider services,
        string slug,
        string name,
        LifecycleState state = LifecycleState.Active,
        DateTimeOffset? lastReachableAt = null,
        bool isClaimed = false,
        CancellationToken ct = default)
    {
        var game = new Game(
            Guid.NewGuid(), slug, name, state, isClaimed,
            Now - TimeSpan.FromDays(400),
            lastReachableAt ?? Now - TimeSpan.FromMinutes(10),
            state == LifecycleState.Archived ? Now - TimeSpan.FromDays(30) : null);

        var id = await services.GetRequiredService<IGameRepository>().InsertAsync(game, ct);
        return game with { Id = id };
    }

    public static Task FieldAsync(
        IServiceProvider services, Guid gameId, string field, string value, FieldSource source,
        DateTimeOffset? lastConfirmedAt = null, CancellationToken ct = default)
        => services.GetRequiredService<IGameFieldRepository>().UpsertAsync(
            new GameField(
                gameId, field, value, source,
                source is FieldSource.Handshake or FieldSource.Who
                    ? FieldConfidence.Observed
                    : FieldConfidence.Reported,
                Now - TimeSpan.FromDays(365),
                lastConfirmedAt ?? Now - TimeSpan.FromMinutes(10)),
            ct);

    public static Task ChangeAsync(
        IServiceProvider services, Guid gameId, string field, string? oldValue, string newValue,
        FieldSource source, DateTimeOffset at, CancellationToken ct = default)
        => services.GetRequiredService<IGameFieldRepository>().AppendChangeAsync(
            new FieldChange(0, gameId, field, oldValue, newValue, source, at), ct);

    public static Task EndpointAsync(
        IServiceProvider services, Guid gameId, string host, int port,
        EndpointKind kind = EndpointKind.Telnet, EndpointState state = EndpointState.Active,
        CancellationToken ct = default)
        => services.GetRequiredService<IEndpointRepository>().UpsertAsync(
            new GameEndpoint(gameId, host, port, kind, Now - TimeSpan.FromDays(300), Now, state), ct);

    /// <summary>A counted sample. <paramref name="count"/> of 0 is a measured zero, which is a fact.</summary>
    public static async Task PresenceAsync(
        IServiceProvider services, Guid gameId, DateTimeOffset at, int? count,
        string? unmeasurableReason = null, PresenceSource source = PresenceSource.Who,
        CancellationToken ct = default)
    {
        var presence = services.GetRequiredService<IPresenceRepository>();
        await presence.EnsurePartitionAsync(at, ct);
        await presence.AppendAsync(new PresenceSample(gameId, at, count, source, unmeasurableReason, null), ct);
    }

    public static async Task<long> AvailabilityAsync(
        IServiceProvider services, Guid gameId, AvailabilityState state, FailureCause cause,
        DateTimeOffset from, DateTimeOffset? to = null, CancellationToken ct = default)
    {
        var availability = services.GetRequiredService<IAvailabilityRepository>();
        var id = await availability.OpenAsync(gameId, state, cause, from, ct);
        if (to is not null)
        {
            await availability.CloseAsync(id, to.Value, ct);
        }

        return id;
    }
}
```

```csharp
using MUI.Catalog;
using MUI.Web.ViewModels;

namespace MUI.Web;

/// <summary>
/// Pairs what the handshake observed with what the game claimed (spec §3.1, §9).
/// </summary>
/// <remarks>
/// Spec §5.1 stores one row per (game, field), so the measured and declared answers for the same
/// protocol cannot share a field name — they are stored under a prefixed pair, and this is where the
/// pair is put back together. The column a row lands in is decided by its <see cref="FieldSource"/>
/// and not by its prefix: an observation is <c>handshake</c> and everything else is a claim, which is
/// exactly the dichotomy §3.1 draws. Where two rows compete for the same column,
/// <see cref="SourcePrecedence"/> settles it rather than declaration order.
/// </remarks>
internal static class CapabilityMatrix
{
    // No prefixes are declared here. The names are Plan 02's (MUI.Catalog.CapabilityFields), because
    // the project that writes the rows owns what they are called; a second spelling in the read tier
    // would be a vocabulary that drifts.
    public static bool IsCapability(string field) =>
        field.StartsWith(CapabilityFields.Prefix, StringComparison.OrdinalIgnoreCase)
        || SourcePrecedence.IsCapabilityField(field);

    public static IReadOnlyList<CapabilityView> Build(IReadOnlyList<GameField> fields, DateTimeOffset now) =>
        fields
            .Where(f => IsCapability(f.Field))
            .GroupBy(f => Bare(f.Field), StringComparer.OrdinalIgnoreCase)
            .OrderBy(g => g.Key, StringComparer.Ordinal)
            .Select(group =>
            {
                var measured = Winner(group.Where(f => f.Source is FieldSource.Handshake));
                var declared = Winner(group.Where(f => f.Source is not FieldSource.Handshake));

                return new CapabilityView(
                    group.Key,
                    AsFlag(measured?.Value),
                    AsFlag(declared?.Value),
                    measured is null ? null : ProvenanceView.From(measured, now),
                    declared is null ? null : ProvenanceView.From(declared, now));
            })
            .ToList();

    public static bool? AsFlag(string? value) => value?.Trim().ToLowerInvariant() switch
    {
        null => null,
        "1" or "true" or "yes" or "on" => true,
        "0" or "false" or "no" or "off" => false,
        _ => null,
    };

    private static GameField? Winner(IEnumerable<GameField> candidates) =>
        candidates.OrderBy(f => SourcePrecedence.RankOf(f.Source)).FirstOrDefault();

    /// <summary>
    /// <c>capability.gmcp.measured</c> and <c>capability.gmcp.declared</c> both reduce to <c>gmcp</c>,
    /// which is what the two sides are grouped on. A field carrying neither suffix is returned as it
    /// stands, so a capability stored under a bare name still groups with itself.
    /// </summary>
    private static string Bare(string field)
    {
        var name = field.StartsWith(CapabilityFields.Prefix, StringComparison.OrdinalIgnoreCase)
            ? field[CapabilityFields.Prefix.Length..]
            : field;

        if (name.EndsWith(CapabilityFields.MeasuredSuffix, StringComparison.OrdinalIgnoreCase))
        {
            return name[..^CapabilityFields.MeasuredSuffix.Length];
        }

        return name.EndsWith(CapabilityFields.DeclaredSuffix, StringComparison.OrdinalIgnoreCase)
            ? name[..^CapabilityFields.DeclaredSuffix.Length]
            : name;
    }
}
```

```csharp
using MUI.Catalog;
using MUI.Web.ViewModels;

namespace MUI.Web;

/// <summary>
/// Reachable-over-a-window and longest-outage, as arithmetic over a handful of interval rows
/// (spec §5.3). This is the only place either number is computed: the collection surface, the game
/// page, the dump and the rankings all call it, so they cannot disagree.
/// </summary>
internal static class ReachabilityCalculator
{
    public const int WindowDays = 90;

    /// <param name="lastReachableAt">
    /// The game's own <c>last_reachable_at</c>, passed in rather than derived, because a game dark for
    /// two years has nothing reachable inside the window and the date is still a fact worth showing.
    /// </param>
    public static ReachabilityView Compute(
        IReadOnlyList<AvailabilityInterval> intervals,
        DateTimeOffset? lastReachableAt,
        DateTimeOffset now,
        int windowDays = WindowDays)
    {
        var from = now - TimeSpan.FromDays(windowDays);
        var reachable = TimeSpan.Zero;
        var longestOutage = TimeSpan.Zero;

        foreach (var interval in intervals)
        {
            var start = interval.FromAt < from ? from : interval.FromAt;
            var end = interval.ToAt ?? now;
            if (end > now)
            {
                end = now;
            }

            if (end <= start)
            {
                continue;
            }

            var span = end - start;

            switch (interval.State)
            {
                case AvailabilityState.Reachable:
                    reachable += span;
                    break;
                case AvailabilityState.Unreachable when span > longestOutage:
                    longestOutage = span;
                    break;
            }
        }

        var window = now - from;
        var percent = window <= TimeSpan.Zero ? 0d : reachable / window * 100d;

        return new ReachabilityView(Math.Round(percent, 2), windowDays, longestOutage, lastReachableAt);
    }
}
```

```csharp
using MUI.Catalog;
using MUI.Discovery;
using MUI.Storage;
using MUI.Web.ViewModels;

namespace MUI.Web;

public sealed class ViewModelBuilder(
    IGameRepository games,
    IGameFieldRepository fields,
    IAvailabilityRepository availability,
    IEndpointRepository endpoints,
    IPresenceRepository presence,
    IReferralRepository referrals) : IViewModelBuilder
{
    public const int RecentChangeLimit = 20;

    public async Task<GameView?> GameAsync(string slug, DateTimeOffset now, CancellationToken ct)
    {
        var game = await games.BySlugAsync(slug, ct);
        if (game is null)
        {
            return null;
        }

        var window = now - TimeSpan.FromDays(ReachabilityCalculator.WindowDays);
        var rows = await fields.ForGameAsync(game.Id, ct);
        var changes = await fields.ChangesAsync(game.Id, RecentChangeLimit, ct);
        var intervals = await availability.RangeAsync(game.Id, window, now, ct);
        var addresses = await endpoints.ForGameAsync(game.Id, ct);
        var edges = await referrals.FromGameAsync(game.Id, ct);

        var suppressed = CapabilityMatrix.AsFlag(Value(rows, WellKnownFields.ConnectScreenSuppressed)) is true;

        return new GameView(
            game.Id.ToString(),
            game.Slug,
            game.Name,
            LifecycleName(game.State),
            Value(rows, WellKnownFields.Tagline),
            Value(rows, WellKnownFields.Description),
            addresses.Select(EndpointOf).ToList(),
            suppressed ? null : Value(rows, WellKnownFields.ConnectScreen),
            rows.Where(f => !CapabilityMatrix.IsCapability(f.Field))
                .OrderBy(f => f.Field, StringComparer.Ordinal)
                .Select(f => FieldView.From(f, now))
                .ToList(),
            CapabilityMatrix.Build(rows, now),
            ReachabilityCalculator.Compute(intervals, game.LastReachableAt, now),
            changes.Select(c => new ChangeView(
                    c.Field, c.OldValue, c.NewValue, ProvenanceView.SourceName(c.Source), c.At))
                .ToList(),
            edges.Select(e => new EndpointView(
                    e.ToHost, e.ToPort, EndpointKindName(EndpointKind.Telnet),
                    e.Present ? EndpointStateName(EndpointState.Active) : EndpointStateName(EndpointState.Gone),
                    e.FirstSeenAt, e.LastSeenAt))
                .ToList());
    }

    public Task<CollectionView<GameSummaryView>> GamesAsync(GameQuery query, DateTimeOffset now, CancellationToken ct)
        => throw new NotImplementedException("Task 6.");

    public Task<IReadOnlyList<PresencePointView>> PresenceAsync(
        string slug, DateTimeOffset from, DateTimeOffset to, CancellationToken ct)
        => throw new NotImplementedException("Task 7.");

    public Task<IReadOnlyList<AvailabilitySpanView>> AvailabilityAsync(
        string slug, DateTimeOffset from, DateTimeOffset to, CancellationToken ct)
        => throw new NotImplementedException("Task 7.");

    internal static string LifecycleName(LifecycleState state) => state switch
    {
        LifecycleState.Active => "active",
        LifecycleState.Quiet => "quiet",
        LifecycleState.Dark => "dark",
        LifecycleState.Archived => "archived",
        _ => "unknown",
    };

    internal static string EndpointKindName(EndpointKind kind) => kind switch
    {
        EndpointKind.Telnet => "telnet",
        EndpointKind.Tls => "tls",
        EndpointKind.WebSocket => "websocket",
        EndpointKind.Http => "http",
        _ => "unknown",
    };

    internal static string EndpointStateName(EndpointState state) => state switch
    {
        EndpointState.Active => "active",
        EndpointState.Stale => "stale",
        EndpointState.Gone => "gone",
        _ => "unknown",
    };

    internal static string? Value(IReadOnlyList<GameField> rows, string field) =>
        rows.Where(f => string.Equals(f.Field, field, StringComparison.OrdinalIgnoreCase))
            .OrderBy(f => SourcePrecedence.RankOf(f.Source))
            .Select(f => f.Value)
            .FirstOrDefault();

    private static EndpointView EndpointOf(GameEndpoint endpoint) =>
        new(endpoint.Host, endpoint.Port, EndpointKindName(endpoint.Kind),
            EndpointStateName(endpoint.State), endpoint.FirstSeenAt, endpoint.LastSeenAt);
```

`src/MUI.Web/PlainRenderer.cs`:

```csharp
using System.Collections;
using System.Reflection;
using System.Text;
using System.Text.Json;

namespace MUI.Web;

/// <summary>
/// The plain surface (spec §9). It renders the same view models the JSON surface does, reflectively,
/// so a fact cannot be present in one and missing from the other: there is no second document to
/// drift into. Property names are camel-cased exactly as the JSON serialiser camel-cases them and
/// leaf values are formatted by the JSON serialiser itself, so the two cannot disagree about spelling
/// either. <c>SurfaceParityTests</c> is the pin.
/// </summary>
public static class PlainRenderer
{
    /// <summary>The marker that opens a multi-line value; its lines follow, indented by two spaces.</summary>
    private const string BlockMarker = "|";

    public static string Render(object viewModel) => Render(viewModel, string.Empty);

    /// <param name="path">A path prefix, so a streamed dump can nest each item under <c>games[7]</c>.</param>
    public static string Render(object viewModel, string path)
    {
        ArgumentNullException.ThrowIfNull(viewModel);

        var builder = new StringBuilder();
        Write(builder, path, viewModel);
        return builder.ToString();
    }

    private static void Write(StringBuilder builder, string path, object? value)
    {
        if (value is null || IsLeaf(value.GetType()))
        {
            WriteLeaf(builder, path, value);
            return;
        }

        if (value is IEnumerable items)
        {
            var index = 0;
            foreach (var item in items)
            {
                Write(builder, $"{path}[{index}]", item);
                index++;
            }

            return;
        }

        foreach (var property in value.GetType().GetProperties(BindingFlags.Public | BindingFlags.Instance))
        {
            if (property.GetIndexParameters().Length != 0)
            {
                continue;
            }

            var name = JsonNamingPolicy.CamelCase.ConvertName(property.Name);
            Write(builder, path.Length == 0 ? name : $"{path}.{name}", property.GetValue(value));
        }
    }

    private static void WriteLeaf(StringBuilder builder, string path, object? value)
    {
        var text = Format(value);

        if (!text.Contains('\n') && text != BlockMarker)
        {
            builder.Append(path).Append(": ").Append(text).Append('\n');
            return;
        }

        builder.Append(path).Append(": ").Append(BlockMarker).Append('\n');
        foreach (var line in text.Split('\n'))
        {
            builder.Append("  ").Append(line).Append('\n');
        }
    }

    private static string Format(object? value)
    {
        if (value is null)
        {
            return "(null)";
        }

        if (value is string text)
        {
            return text;
        }

        var json = JsonSerializer.Serialize(value, value.GetType(), JsonOptions.Default);
        return json.Length >= 2 && json[0] == '"' ? JsonSerializer.Deserialize<string>(json)! : json;
    }

    private static bool IsLeaf(Type type)
    {
        var bare = Nullable.GetUnderlyingType(type) ?? type;

        return bare.IsPrimitive
            || bare.IsEnum
            || bare == typeof(string)
            || bare == typeof(decimal)
            || bare == typeof(DateTimeOffset)
            || bare == typeof(DateTime)
            || bare == typeof(TimeSpan)
            || bare == typeof(Guid)
            || bare == typeof(Uri);
    }
}
```

```csharp
using System.Security.Cryptography;
using System.Text.Json;

namespace MUI.Web;

/// <summary>
/// A strong entity tag over the canonical JSON of a view model (spec §10). Records serialise their
/// properties in declaration order, so the same view model always produces the same bytes and the
/// same tag; nothing here may be handed a dictionary, whose ordering is not guaranteed.
/// </summary>
public static class ETag
{
    public static string For<T>(T value)
    {
        var canonical = JsonSerializer.SerializeToUtf8Bytes(value, JsonOptions.Default);
        return $"\"{Convert.ToHexStringLower(SHA256.HashData(canonical))}\"";
    }
}
```

```csharp
using System.Text.Json;
using Microsoft.Net.Http.Headers;

namespace MUI.Web;

/// <summary>
/// The one place a view model becomes bytes: the representation is chosen, the ETag is set, and a
/// conditional request is answered. Every endpoint goes through this, which is why "does the plain
/// surface carry the same facts" is one question with one answer rather than one per route.
/// </summary>
internal static class ViewResponse
{
    public const string JsonContentType = "application/json; charset=utf-8";
    public const string PlainContentType = "text/plain; charset=utf-8";

    public static Task WriteAsync<TView>(HttpContext http, TView view, CancellationToken ct) =>
        WriteAsync(http, view, static v => JsonSerializer.Serialize(v, JsonOptions.Default), JsonContentType, ct);

    public static async Task WriteAsync<TView>(
        HttpContext http, TView view, Func<TView, string> renderRich, string richContentType, CancellationToken ct)
    {
        if (TryNotModified(http, ETag.For(view)))
        {
            return;
        }

        var plain = PrefersPlain(http.Request);

        http.Response.StatusCode = StatusCodes.Status200OK;
        http.Response.ContentType = plain ? PlainContentType : richContentType;
        await http.Response.WriteAsync(plain ? PlainRenderer.Render(view!) : renderRich(view), ct);
    }

    /// <summary>
    /// Sets the validator and answers a matching <c>If-None-Match</c> with a bodiless 304. The tag is
    /// over the view model rather than over the rendered bytes: the representation is selected by the
    /// URI (<c>?plain=1</c>) or by <c>Accept</c>, and <c>Vary: Accept</c> says so.
    /// </summary>
    public static bool TryNotModified(HttpContext http, string etag)
    {
        http.Response.Headers[HeaderNames.ETag] = etag;
        http.Response.Headers[HeaderNames.Vary] = HeaderNames.Accept;

        if (!http.Request.Headers.TryGetValue(HeaderNames.IfNoneMatch, out var candidates))
        {
            return false;
        }

        var matched = candidates.Any(candidate => candidate is not null
            && candidate.Split(',').Any(tag => tag.Trim() is var trimmed && (trimmed == "*" || trimmed == etag)));

        if (matched)
        {
            http.Response.StatusCode = StatusCodes.Status304NotModified;
        }

        return matched;
    }

    /// <summary>Spec §9: plain mode is asked for, or inferred for a text browser.</summary>

    {

            && flag.Any(value => value is "1" or "true"))

            return true;

            || agent.Contains("w3m", StringComparison.OrdinalIgnoreCase)
            || agent.Contains("ELinks", StringComparison.OrdinalIgnoreCase)
            || agent.Contains("Links ", StringComparison.OrdinalIgnoreCase))
        {
            return true;
        }

        var accept = request.Headers.Accept.ToString();
        return accept.Contains("text/plain", StringComparison.OrdinalIgnoreCase)
            && !accept.Contains("text/html", StringComparison.OrdinalIgnoreCase)
            && !accept.Contains("application/json", StringComparison.OrdinalIgnoreCase);
```

```csharp
using System.Text.Json;

namespace MUI.Web.Tests.Support;

/// <summary>
/// Reduces either surface to the same thing: a map of leaf path to leaf value. Two responses carry
/// the same facts exactly when these maps are equal, which is the property spec §9 asks for — "the
/// graphical game page is the plain page with graphics added, not a second document".
/// </summary>
public static class Facts
{
    public static IReadOnlyDictionary<string, string> FromJson(string json)
    {
        var facts = new Dictionary<string, string>(StringComparer.Ordinal);
        using var document = JsonDocument.Parse(json);
        Walk(document.RootElement, string.Empty, facts);
        return facts;
    }

    public static IReadOnlyDictionary<string, string> FromPlain(string text)
    {
        var facts = new Dictionary<string, string>(StringComparer.Ordinal);
        var lines = text.Split('\n');

        for (var i = 0; i < lines.Length; i++)
        {
            var line = lines[i];
            if (line.Length == 0)
            {
                continue;
            }

            var separator = line.IndexOf(": ", StringComparison.Ordinal);
            if (separator < 0)
            {
                continue;
            }

            var path = line[..separator];
            var value = line[(separator + 2)..];

            if (value == "|")
            {
                var block = new List<string>();
                while (i + 1 < lines.Length && lines[i + 1].StartsWith("  ", StringComparison.Ordinal))
                {
                    block.Add(lines[++i][2..]);
                }

                value = string.Join('\n', block);
            }

            facts[path] = value;
        }

        return facts;
    }

    /// <summary>A sorted, diffable rendering, so a failure names the fact that went missing.</summary>
    public static string Describe(IReadOnlyDictionary<string, string> facts) =>
        string.Join('\n', facts.Select(fact => $"{fact.Key} = {fact.Value}").Order(StringComparer.Ordinal));

    private static void Walk(JsonElement element, string path, Dictionary<string, string> facts)
    {
        switch (element.ValueKind)
        {
            case JsonValueKind.Object:
                foreach (var property in element.EnumerateObject())
                {
                    Walk(property.Value, path.Length == 0 ? property.Name : $"{path}.{property.Name}", facts);
                }

                break;

            case JsonValueKind.Array:
                var index = 0;
                foreach (var item in element.EnumerateArray())
                {
                    Walk(item, $"{path}[{index++}]", facts);
                }

                break;

            case JsonValueKind.Null:
                facts[path] = "(null)";
                break;

            case JsonValueKind.String:
                facts[path] = element.GetString()!;
                break;

            default:
                facts[path] = element.GetRawText();
                break;
        }
    }
}
```

```csharp
using MUI.Storage;

namespace MUI.Web.Endpoints;

public static class SeriesEndpoints
{
    public static readonly TimeSpan DefaultWindow = TimeSpan.FromDays(30);

    /// <summary>A window wide enough for a year of heatmap and no wider — a range is not a licence
    /// to scan the whole partition set.</summary>
    public static readonly TimeSpan MaxWindow = TimeSpan.FromDays(366);

    public static void Map(IEndpointRouteBuilder app)
    {
        app.MapGet("/api/v1/games/{slug}/presence", async (
            string slug, HttpContext http, IViewModelBuilder builder, IGameRepository games,
            TimeProvider time, CancellationToken ct) =>
        {
            if (await games.BySlugAsync(slug, ct) is null)
            {
                http.Response.StatusCode = StatusCodes.Status404NotFound;
                return;
            }

            var (from, to) = WindowFrom(http.Request, time.GetUtcNow());
            await ViewResponse.WriteAsync(http, await builder.PresenceAsync(slug, from, to, ct), ct);
        });

        app.MapGet("/api/v1/games/{slug}/availability", async (
            string slug, HttpContext http, IViewModelBuilder builder, IGameRepository games,
            TimeProvider time, CancellationToken ct) =>
        {
            if (await games.BySlugAsync(slug, ct) is null)
            {
                http.Response.StatusCode = StatusCodes.Status404NotFound;
                return;
            }

            var (from, to) = WindowFrom(http.Request, time.GetUtcNow());
            await ViewResponse.WriteAsync(http, await builder.AvailabilityAsync(slug, from, to, ct), ct);
        });
    }

    internal static (DateTimeOffset From, DateTimeOffset To) WindowFrom(HttpRequest request, DateTimeOffset now)
    {
        var to = Parse(request.Query["to"]) ?? now;
        if (to > now)
        {
            to = now;
        }

        var from = Parse(request.Query["from"]) ?? to - DefaultWindow;
        if (from >= to)
        {
            from = to - DefaultWindow;
        }

        return (to - from > MaxWindow ? to - MaxWindow : from, to);
    }

    private static DateTimeOffset? Parse(string? value) =>
        DateTimeOffset.TryParse(value, CultureInfo.InvariantCulture, DateTimeStyles.AdjustToUniversal, out var parsed)
            ? parsed
            : null;
}
```

```csharp
using Dapper;
using MUI.Catalog;
using Npgsql;

namespace MUI.Storage;

/// <summary>How many games there are and when the catalogue last changed — the dump's validator.</summary>
public sealed record DatasetVersion(int Games, int ActiveGames, DateTimeOffset? LatestChangeAt);

/// <summary>One slice of the measured set. A count, never a population.</summary>
public sealed record ShareRow(string Name, int Games);

public interface IEcosystemReader
{
    Task<DatasetVersion> VersionAsync(CancellationToken ct);

    Task<IReadOnlyList<ShareRow>> CodebaseSharesAsync(CancellationToken ct);

    Task<IReadOnlyList<ShareRow>> CapabilitySharesAsync(CancellationToken ct);
}

public sealed class EcosystemReader(NpgsqlDataSource source) : IEcosystemReader
{
    private static readonly string Archived = nameof(LifecycleState.Archived).ToLowerInvariant();
    private static readonly string Handshake = nameof(FieldSource.Handshake).ToLowerInvariant();

    public async Task<DatasetVersion> VersionAsync(CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        return await connection.QuerySingleAsync<DatasetVersion>(new CommandDefinition(
            """
            SELECT (SELECT count(*) FROM game) AS games,
                   (SELECT count(*) FROM game WHERE state <> @archived) AS active_games,
                   (SELECT max(at) FROM field_change) AS latest_change_at
            """,
            new { archived = Archived },
            cancellationToken: ct));
    }

    public async Task<IReadOnlyList<ShareRow>> CodebaseSharesAsync(CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        var rows = await connection.QueryAsync<ShareRow>(new CommandDefinition(
            """
            SELECT f.value AS name, count(*) AS games
            FROM game_field f
            JOIN game g ON g.id = f.game_id
            WHERE lower(f.field) = @codebaseField AND g.state <> @archived
            GROUP BY f.value
            ORDER BY count(*) DESC, f.value
            """,
            new { codebaseField = "codebase", archived = Archived },
            cancellationToken: ct));

        return rows.ToList();
    }

    /// <summary>
    /// Adoption is counted from the handshake and never from a claim (spec §3.1): a game saying
    /// <c>GMCP 1</c> is an assertion, and an assertion is not adoption.
    /// </summary>
    public async Task<IReadOnlyList<ShareRow>> CapabilitySharesAsync(CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        var rows = await connection.QueryAsync<ShareRow>(new CommandDefinition(
            """
            SELECT f.field AS name, count(*) AS games
            FROM game_field f
            JOIN game g ON g.id = f.game_id
            WHERE f.source = @handshake AND g.state <> @archived
              AND lower(f.value) IN ('1', 'true', 'yes', 'on')
            GROUP BY f.field
            ORDER BY count(*) DESC, f.field
            """,
            new { handshake = Handshake, archived = Archived },
            cancellationToken: ct));

        return rows.ToList();
    }
}
```

```csharp
using System.Text;
using System.Text.Json;
using Microsoft.Extensions.Options;
using MUI.Storage;
using MUI.Web.ViewModels;

namespace MUI.Web.Endpoints;

public static class DumpEndpoints
{
    public const int PageSize = 200;

    public static void Map(IEndpointRouteBuilder app)
    {
        app.MapGet("/api/v1/dumps/games.json", async (
            HttpContext http, IViewModelBuilder builder, IEcosystemReader ecosystem,
            IAttributionSource attribution, IOptions<DatasetLicenceOptions> licence,
            TimeProvider time, CancellationToken ct) =>
        {
            var now = time.GetUtcNow();
            var version = await ecosystem.VersionAsync(ct);
            var stamp = new DumpVersionView(version.Games, version.LatestChangeAt, licence.Value.Licence);

            if (ViewResponse.TryNotModified(http, ETag.For(stamp)))
            {
                return;
            }

            var header = new DumpHeaderView(
                licence.Value.Licence, licence.Value.LicenceUri, now, attribution.Attributions);
            var plain = ViewResponse.PrefersPlain(http.Request);

            http.Response.StatusCode = StatusCodes.Status200OK;
            http.Response.ContentType = plain ? ViewResponse.PlainContentType : ViewResponse.JsonContentType;

            if (plain)
            {
                await WritePlainAsync(http, builder, header, now, ct);
                return;
            }

            await WriteJsonAsync(http, builder, header, now, ct);
        });
    }

    private static async Task WriteJsonAsync(
        HttpContext http, IViewModelBuilder builder, DumpHeaderView header, DateTimeOffset now, CancellationToken ct)
    {
        await using var writer = new Utf8JsonWriter(http.Response.BodyWriter);

        writer.WriteStartObject();
        writer.WriteString("licence", header.Licence);
        if (header.LicenceUri is null)
        {
            writer.WriteNull("licenceUri");
        }
        else
        {
            writer.WriteString("licenceUri", header.LicenceUri);
        }

        writer.WriteString("generatedAt", header.GeneratedAt);
        writer.WritePropertyName("attribution");
        JsonSerializer.Serialize(writer, header.Attribution, JsonOptions.Default);
        writer.WriteStartArray("games");

        await foreach (var game in PagesAsync(builder, now, ct))
        {
            JsonSerializer.Serialize(writer, game, JsonOptions.Default);
            if (writer.BytesPending > 16 * 1024)
            {
                await writer.FlushAsync(ct);
                await http.Response.BodyWriter.FlushAsync(ct);
            }
        }

        writer.WriteEndArray();
        writer.WriteEndObject();
        await writer.FlushAsync(ct);
    }

    private static async Task WritePlainAsync(
        HttpContext http, IViewModelBuilder builder, DumpHeaderView header, DateTimeOffset now, CancellationToken ct)
    {
        await http.Response.WriteAsync(PlainRenderer.Render(header), Encoding.UTF8, ct);

        var index = 0;
        await foreach (var game in PagesAsync(builder, now, ct))
        {
            await http.Response.WriteAsync(PlainRenderer.Render(game, $"games[{index++}]"), Encoding.UTF8, ct);
        }
    }

    /// <summary>
    /// Paged rather than materialised: the dump is the whole catalogue and must never be one list in
    /// memory. Archived games are included — the dump is the historical record (spec §7.5), and each
    /// game carries its own <c>state</c>.
    /// </summary>
    private static async IAsyncEnumerable<GameSummaryView> PagesAsync(
        IViewModelBuilder builder,
        DateTimeOffset now,
        [System.Runtime.CompilerServices.EnumeratorCancellation] CancellationToken ct)
    {
        for (var offset = 0; ; offset += PageSize)
        {
            var page = await builder.GamesAsync(
                new GameQuery { IncludeArchived = true, Limit = PageSize, Offset = offset }, now, ct);

            foreach (var game in page.Items)
            {
                yield return game;
            }

            if (page.Items.Count < PageSize)
            {
                yield break;
            }
        }
    }
}
```

```csharp
using Dapper;
using MUI.Catalog;
using Npgsql;

namespace MUI.Storage;

/// <summary>One line of a liveness feed: which game, when, and what happened.</summary>
public sealed record FeedRow(Guid GameId, string Slug, string Name, DateTimeOffset At, string? Detail);

public interface IFeedReader
{
    Task<IReadOnlyList<FeedRow>> DiscoveredAsync(int limit, CancellationToken ct);

    Task<IReadOnlyList<FeedRow>> WentDarkAsync(int limit, CancellationToken ct);

    Task<IReadOnlyList<FeedRow>> CameBackAsync(int limit, CancellationToken ct);
}

/// <summary>
/// The three feeds spec §9 calls the product differentiator. Each is a query over what the crawler
/// already recorded — a game's first sighting, and the transitions between availability intervals.
/// </summary>
public sealed class FeedReader(NpgsqlDataSource source) : IFeedReader
{
    private static readonly string Reachable = nameof(AvailabilityState.Reachable).ToLowerInvariant();

    public async Task<IReadOnlyList<FeedRow>> DiscoveredAsync(int limit, CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        var rows = await connection.QueryAsync<FeedRow>(new CommandDefinition(
            """
            SELECT id AS game_id, slug, name, first_seen_at AS at, NULL::text AS detail
            FROM game
            ORDER BY first_seen_at DESC
            LIMIT @limit
            """,
            new { limit },
            cancellationToken: ct));

        return rows.ToList();
    }

    public async Task<IReadOnlyList<FeedRow>> WentDarkAsync(int limit, CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        var rows = await connection.QueryAsync<FeedRow>(new CommandDefinition(
            """
            SELECT g.id AS game_id, g.slug, g.name, i.from_at AS at, i.cause AS detail
            FROM availability_interval i
            JOIN game g ON g.id = i.game_id
            WHERE i.state <> @reachable
              AND EXISTS (SELECT 1 FROM availability_interval prior
                          WHERE prior.game_id = i.game_id AND prior.state = @reachable
                            AND prior.to_at = i.from_at)
            ORDER BY i.from_at DESC
            LIMIT @limit
            """,
            new { reachable = Reachable, limit },
            cancellationToken: ct));

        return rows.ToList();
    }

    public async Task<IReadOnlyList<FeedRow>> CameBackAsync(int limit, CancellationToken ct)
    {
        await using var connection = await source.OpenConnectionAsync(ct);
        var rows = await connection.QueryAsync<FeedRow>(new CommandDefinition(
            """
            SELECT g.id AS game_id, g.slug, g.name, i.from_at AS at, prior.cause AS detail
            FROM availability_interval i
            JOIN game g ON g.id = i.game_id
            JOIN availability_interval prior
              ON prior.game_id = i.game_id AND prior.to_at = i.from_at AND prior.state <> @reachable
            WHERE i.state = @reachable
            ORDER BY i.from_at DESC
            LIMIT @limit
            """,
            new { reachable = Reachable, limit },
            cancellationToken: ct));

        return rows.ToList();
    }
}
```

```csharp
    public static string For(string feed, Guid gameId, DateTimeOffset at) =>
        string.Create(CultureInfo.InvariantCulture,
            $"mui:{feed}:{gameId:N}:{at.ToUniversalTime():yyyyMMdd'T'HHmmss'Z'}");
}

public static class RssFeed
{
    public static string Render(string title, Uri self, IEnumerable<FeedItem> items)
    {
        XNamespace atom = "http://www.w3.org/2005/Atom";

        var channel = new XElement("channel",
            new XElement("title", title),
            new XElement("link", self.ToString()),
            new XElement("description", title),
            new XElement(atom + "link",
                new XAttribute("href", self.ToString()),
                new XAttribute("rel", "self"),
                new XAttribute("type", "application/rss+xml")));

        foreach (var item in items)
        {
            channel.Add(new XElement("item",
                new XElement("title", item.Title),
                new XElement("link", item.Link.ToString()),
                new XElement("description", item.Description),
                new XElement("pubDate", item.PublishedAt.ToUniversalTime().ToString("r", CultureInfo.InvariantCulture)),
                new XElement("guid", new XAttribute("isPermaLink", "false"), item.Guid)));
        }

        var document = new XDocument(
            new XDeclaration("1.0", "utf-8", null),
            new XElement("rss",
                new XAttribute("version", "2.0"),
                new XAttribute(XNamespace.Xmlns + "atom", atom),
                channel));

        using var writer = new Utf8StringWriter();
        document.Save(writer, SaveOptions.None);
        return writer.ToString();
    }

    private sealed class Utf8StringWriter : StringWriter
    {
        public override Encoding Encoding => Encoding.UTF8;
    }
}
```

```csharp
using MUI.Storage;
using MUI.Web.ViewModels;

namespace MUI.Web.Endpoints;

public static class EcosystemEndpoints
{
    /// <summary>How many measured games a ranking is drawn from before it is paged.</summary>
    public const int RankingPool = 500;

    public static class RankingKeys
    {
        public const string Reachable = "reachable";
        public const string Presence = "presence";

        public static readonly string[] All = [Reachable, Presence];
    }

    public static void Map(IEndpointRouteBuilder app)
    {
        app.MapGet("/api/v1/ecosystem/shares", async (
            HttpContext http, IEcosystemReader ecosystem, TimeProvider time, CancellationToken ct) =>
        {
            var version = await ecosystem.VersionAsync(ct);
            var codebases = await ecosystem.CodebaseSharesAsync(ct);
            var capabilities = await ecosystem.CapabilitySharesAsync(ct);

            var view = new EcosystemView(
                version.ActiveGames,
                Shares(codebases, version.ActiveGames),
                Shares(capabilities, version.ActiveGames),
                time.GetUtcNow());

            await ViewResponse.WriteAsync(http, view, ct);
        });

        app.MapGet("/api/v1/rankings", async (
            HttpContext http, IViewModelBuilder builder, TimeProvider time, CancellationToken ct) =>
        {
            var by = http.Request.Query["by"].ToString();
            if (by.Length == 0)
            {
                by = RankingKeys.Reachable;
            }

            if (!RankingKeys.All.Contains(by, StringComparer.Ordinal))
            {
                http.Response.StatusCode = StatusCodes.Status400BadRequest;
                return;
            }

            var now = time.GetUtcNow();

            // Archived games are out of the rankings (spec §7.5), and the only inputs are measured
            // ones: reachable time and an observed player count. There is no user-supplied signal in
            // this request to read, and there never will be (spec §2).
            var pool = await builder.GamesAsync(
                new GameQuery { IncludeArchived = false, Limit = RankingPool, Offset = 0 }, now, ct);

            var ordered = by == RankingKeys.Reachable
                ? pool.Items.OrderByDescending(g => g.Reachable.ReachablePercent)
                    .ThenBy(g => g.Slug, StringComparer.Ordinal)
                : pool.Items.OrderByDescending(g => g.PlayersNow ?? -1)
                    .ThenBy(g => g.Slug, StringComparer.Ordinal);

            var query = GameEndpoints.QueryFrom(http.Request);
            var page = ordered.Skip(query.Offset).Take(query.Limit).ToList();

            await ViewResponse.WriteAsync(
                http, new CollectionView<GameSummaryView>(page, pool.Total, query.Offset, query.Limit, false), ct);
        });
    }

    private static IReadOnlyList<ShareView> Shares(IReadOnlyList<ShareRow> rows, int measured) =>
        measured <= 0
            ? []
            : rows.Select(row => new ShareView(row.Name, Math.Round(row.Games * 100d / measured, 2))).ToList();
}
```
